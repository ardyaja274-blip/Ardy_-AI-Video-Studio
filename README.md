# 🎬 AI Video Studio - Silat Betawi

Web app untuk membuat prompt video AI khusus pencak silat Betawi.
Ubah foto latihan silat menjadi video sinematik, tanpa mengubah wajah asli.

## ✨ Fitur Utama

- **Image to Video Silat** - Ubah foto jurus menjadi video bergerak
- **Prompt Generator** - Prompt otomatis untuk PixVerse, Kling, Runway, dan Veo
- **Kunci Wajah** - Wajah asli tetap SAMA PERSIS, tidak berubah
- **Ciri Khas Betawi:**
    - Golok Betawi (bukan keris)
    - Sabuk kopol / sabuk Betawi lebar
    - Pakaian pangsi Betawi
- **Pengaturan Lengkap:**
    - Rasio aspek: 9:16 (Reels/TikTok), 16:9 (YouTube), 1:1
    - Gerakan kamera: zoom in, zoom out, orbit, pan, tracking
    - Durasi: 5s / 10s / 20s
    - Gaya: Sinematik
- **PWA / Installable** - Bisa dipasang di HP seperti aplikasi
- **Download Output** - Simpan prompt & video langsung dari HP

## 🥋 Contoh Gerakan Silat

- Pasang / Sikap awal
- Jurus tangan kosong
- Main golok Betawi
- Tendangan & elakan
- Gerakan lambat sinematik (slow motion)
- Jurus berpasangan

## 🚀 Cara Pakai

1. Buka link website ini
2. Upload foto pose silat kamu
3. Pilih gerakan yang mau dibuat
4. Pilih rasio, gerakan kamera, dan durasi
5. Salin prompt yang dibuat
6. Tempel prompt ke PixVerse / Kling / Runway / Veo
7. Download hasil videonya

## 📝 Contoh Prompt yang Dihasilkan

> Video sinematik pencak silat Betawi, seorang pesilat dengan pakaian
> pangsi dan sabuk kopol lebar, memegang golok Betawi, melakukan jurus
> dengan gerakan tegas dan berwibawa. Kamera orbit perlahan, pencahayaan
> dramatis, kualitas film. Wajah SAMA PERSIS seperti foto asli,
> jangan diubah.
